# Bot Creator plugin support

For help with the Bot Creator documentation plugin in ChatGPT or Codex, email [contact@bot-creator.fr](mailto:contact@bot-creator.fr).

Include the plugin version, the application used, the steps to reproduce the problem and the error message. Remove bot tokens, passwords, API keys and personal information from screenshots and examples. No guaranteed response time is advertised.

The plugin reads public documentation and prepares examples. It cannot access your account, create bots, deploy commands or recover Discord credentials. If documentation tools are unavailable, retry later or read the [official documentation](/docs/).

For installation or import failures, include the validation message shown by ChatGPT or Codex. Access to custom plugins and review features depends on your OpenAI account and the product surface.

Privacy requests are handled at the same email address. See the [privacy policy](/privacy-policy.html#documentation-plugin), [plugin terms of use](/plugin-terms.html), and [publisher information](/legal-notice.html).
