The command catalog is a list of ready-made commands written by the Bot Creator team. You add one to your bot, read it, and adapt it to your server. It replaces the community marketplace, which was removed.

## Where to find it

- **Studio:** Commands, then **Catalog**.
- **Mobile and desktop app:** the "more" menu of the Commands page, then **Catalog**.

You can search by name and filter by category. Everyone sees every command in the catalog.

## Add a command

Press **Add** on a command. It is added to your bot as a normal command that you can read and edit. Review it, then save. Adding a command does not publish it to Discord until you save.

## Premium commands

Each command has its own plan. A command that depends on a Premium feature, such as music, carries a **Premium** badge. On a free account you can still read what it does, but **Add** is locked. A Premium account adds it as usual. The plan is set command by command, not for the whole catalog.

## Tested by the team

Every command in the catalog has been tested before it is published: its script is validated, then it is run for real on a test server of the team, with a text command on a live bot. A command that fails its test is removed from the catalog until it is fixed. The badge **Tested by the team** shows on each card.

Commands are written in BDFD script. Once added, you can edit them like any other command.

## Community commands are closed

Users can no longer publish commands to a shared library, and the marketplace of community templates no longer exists. Only commands written and tested by the team are offered.
