# $sha256 — SHA-256 digest of a text.

## Syntax

```
$sha256[text;(encoding)]
```

## Parameters

- **text** *(text, required)* — The text.
- **encoding** *(text, optional)* — hex (default) or base64.

## Return Value

- string.

## Usage

```
$sha256[a] → ca978112…
```

## Example

```bdfd
$sendMessage[$sha256[a]]
```
