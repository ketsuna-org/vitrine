# $option — Returns an option value with given name (interaction command)

## Syntax

```
$option[optionname]
```

## Parameters

- **optionname** *(text, required)* — The option name to retrieve its value

## Return Value

- Unknown.

## Usage

```
$option[optionname] → result
```

## Example

```bdfd
$option[color]
```
