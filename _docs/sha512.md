# $sha512 — SHA-512 digest of a text.

## Syntax

```
$sha512[text;(encoding)]
```

## Parameters

- **text** *(text, required)* — The text.
- **encoding** *(text, optional)* — hex (default) or base64.

## Return Value

- string.

## Usage

```
$sha512[a] → 1f40fc92…
```

## Example

```bdfd
$sendMessage[$sha512[a]]
```
