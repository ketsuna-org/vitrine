Le parrainage est un donnant-donnant : vous invitez un ami avec votre code personnel, et vous gagnez tous les deux des crédits IA. Chaque bonus est généré par la plateforme. Personne ne donne de crédits à quelqu'un d'autre.

## Votre code personnel

Chaque compte a un code personnel, écrit comme `ABCD-EFGH`. Ouvrez **Réglages > Parrainage** dans l'app mobile ou dans le Studio pour le voir, le copier ou partager un lien qui le contient déjà (`?ref=ABCD-EFGH`). Le code ne change pas.

## Saisir le code d'un ami

Vous pouvez saisir un code à deux endroits :

- **À la connexion avec Discord.** Ouvrez « J'ai un code d'invitation » sur l'écran de connexion et tapez le code, ou ouvrez le lien d'invitation et il est déjà rempli. Le code est appliqué une fois connecté. S'il est refusé, vous êtes connecté quand même et un court message vous dit pourquoi.
- **Dans Réglages > Parrainage**, jusqu'à 7 jours après la création de votre compte.

Vous pouvez saisir un seul code, une seule fois. Vous ne pouvez pas utiliser votre propre code.

## Ce que chacun gagne

| Qui | Quand | Bonus |
|-----|-------|-------|
| L'ami qui saisit le code | Tout de suite | 50 crédits IA |
| Vous, qui avez invité | Pour chaque ami qualifié | 50 crédits IA |
| Vous, à 3 amis qualifiés | Une seule fois | 200 crédits IA en plus |
| Vous, à 10 amis qualifiés | Une seule fois | 7 jours de Premium |

Un ami est **qualifié** quand son compte Discord a plus de 30 jours et que l'un de ses bots a tourné au moins 30 minutes. D'ici là, le parrainage reste en attente et vous ne recevez rien pour lui.

## Limites

- Jusqu'à 20 amis par an comptent pour une même personne.
- La plateforme a un budget mensuel pour les bonus de parrainage. Quand il est épuisé, les nouveaux codes sont refusés jusqu'au mois suivant.
- Un code ne peut être saisi que pendant les 7 premiers jours d'un compte.
- Si un parrainage est annulé, par exemple en cas d'abus, les bonus déjà versés restent à leur propriétaire. Un parrainage annulé ne verse plus rien.

## Confidentialité

Vous voyez seulement combien d'amis sont en attente et qualifiés, et combien de crédits vous avez gagnés. Vous ne voyez jamais qui ils sont. Votre ami ne voit rien de vous non plus.

## Où c'est disponible

Le parrainage est dans l'app mobile (Android et iOS) et dans le Studio. Il n'est pas dans l'app desktop.

Les crédits IA servent au [copilote IA](/fr/docs/ai-copilot/).
