Plugin support

Bot Creator plugin support

For help with the Bot Creator documentation plugin in ChatGPT, Codex or Claude Code, email contact@bot-creator.fr.

contact@bot-creator.fr Plugin terms of use

Writing to us

What to include in your message

Include the plugin version, the application used, the steps to reproduce the problem and the error message. Remove bot tokens, passwords, API keys and personal information from screenshots and examples. No guaranteed response time is advertised.

Scope

What the plugin does and does not do

The plugin reads public documentation and prepares examples. It cannot access your account, create bots, deploy commands or recover Discord credentials. If documentation tools are unavailable, retry later or read the official documentation.

Installation

Installation or import failures

For installation or import failures, include the validation message shown by ChatGPT, Codex or Claude Code. Access to custom plugins and review features depends on your OpenAI or Anthropic account and the product surface. The Claude Code plugin source is on GitHub, where you can also open an issue.

Privacy and legal

Privacy requests and legal pages

Privacy requests are handled at the same email address. See the privacy policy, plugin terms of use, and publisher information.
